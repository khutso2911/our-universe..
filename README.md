For Shanny — A Little Universe of Us
Files and folders
Keep the website files arranged like this:
shanny_website/
├── index.html
├── images/
│   ├── my-favourite-of-shanny.jpg
│   ├── shannys-favourite-of-me.jpg
│   ├── our-first-picture.jpg
│   └── another-picture-of-us.jpg
└── music/
    └── our-song.mp3
How to open the website
1. Extract the project folder if it is in a ZIP file.
2. Make sure the images and music folders are beside index.html.
3. Put your four photos in the images folder using the exact filenames shown above.
4. Put your song in the music folder and name it our-song.mp3.
5. Double-click index.html to open it in a web browser.
Notes
- The HTML, CSS, and JavaScript code in index.html has not been changed; only the filename was changed from index.html.html to index.html.
- The photo and music files are referenced by relative paths. The page will show the photos and play the song only when those files are present at the expected paths.
- The page's live clock uses the visitor's device date and time.
- If you want to publish the site online, upload index.html together with the images and music folders, preserving this structure.
